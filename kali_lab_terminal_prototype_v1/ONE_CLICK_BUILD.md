# One-click Windows build

1. Extract the project ZIP.
2. Open the folder.
3. Double-click `BUILD.bat`.
4. Wait for PyInstaller to finish.
5. A `Kali Lab Terminal.exe` shortcut will be placed on your Desktop.
6. The app will launch automatically.

You do NOT need to open PowerShell manually.

If Windows says Python is missing, install Python 3 and make sure "Add Python to PATH" is selected during installation.
